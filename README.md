# Corporate Resources Network Production Site

Production target: https://crnetwork.com.ng/

## Stack
- React 19
- Vite 8
- Framer Motion
- React Icons

## Local
npm install
npm run dev

## Build
npm install
npm run build

## Render
The included `render.yaml` deploys the project as a static web service and rewrites routes to `index.html`.

## Domain
Attach `crnetwork.com.ng` to the Render static service after deployment. Preserve all existing MX/TXT records and email-related DNS entries when updating the root web record.
