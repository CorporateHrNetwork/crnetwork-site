CHRiS Secure Backup

CHRiS Secure Backup is an internal disaster-recovery utility operated by CorporateHr Network, a service of Corporate Resources Network. It protects the CHRiS human resources and payroll platform used by an authorised client, including Zermatt Liquor Limited.

What it does

The utility exports the authorised CHRiS PostgreSQL database, encrypts the backup on the originating computer using GPG AES-256, and stores the resulting encrypted backup file in a dedicated Google Drive folder controlled by an authorised administrator. It reads encrypted files when checking backup integrity and supports restoration into a separate recovery environment.

Why Google Drive access is requested

The backup utility uses rclone to request Google Drive access. The Google permission can permit access to files beyond the backup folder, but the configured backup workflow is designed to operate only in the dedicated CHRiS backup folder. We do not use Drive contents for marketing, profiling, or advertising.

Privacy and controls. Read the CHRiS Secure Backup privacy notice to learn what data is accessed, how encrypted backups are used, and how permissions can be revoked.

Who can use it

This is an administrative utility, not a public upload service. Access is restricted to authorised administrators acting for the relevant organisation.
